# Générateurs PDF

Chaque générateur est rangé selon le document qu’il produit :

- `commercial-document.js` pour les devis, commandes, factures et avoirs ;
- `subscription-invoice.js` pour les factures d’abonnement ;
- `delivery-note.js` pour les bons de livraison.

Les anciens modules à la racine de `services` restent des façades compatibles pour les contrôleurs existants.
